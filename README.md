# ClubConnect — Campus Clubs & Events

React + Express + MongoDB starter for club discovery, event registration, QR event passes, and a club-admin summary. Seed groups and events let you explore the interface without a database.

Run `npm install`, optionally copy `.env.example` to `.env` and configure MongoDB, then run `npm run dev`. Build with `npm run build` and run with `npm start`.

The sample registration flow uses a demo student identity. Add campus SSO, role-based club administration, QR scan validation, and database-backed event capacity checks before production use.
